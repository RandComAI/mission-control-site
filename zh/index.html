本地 AI 智能体团队控制中心

把多个 AI 会话作为一支团队运行。

RandComp Studio 配合你选择的命令行 AI 工具，围绕同一个项目组织它们的独立会话。用一句话描述想要的结果，项目的协调员会把它拆成具体任务并雇佣帮手。在一款本地应用中查看每个任务由谁负责、产生了什么、哪里需要你。

跟随一个完整工作过程

一个项目，三种控制方式。

先在 Mac 上启动，离开桌面后继续检查，再从另一个 AI 会话中指挥。RandComp 不会因此复制出三个任务。

示例目标：“上线一个小型在线商店。让产品确定范围，开发负责实现，质检独立验证。”

1

在 Mac 前

在桌面应用中看清整个项目。

先用一句话描述你想要什么。项目的协调员会把它拆成一组具体任务，并雇佣帮手完成它们。每个任务都显示谁在负责、产生了什么、哪里需要你。

桌面应用 · 可视化控制
2

离开桌面后

通过 SSH 检查同一支团队。

会话继续在远程电脑上运行。使用轻量命令行——randcomp project list、randcomp project ask——查看哪里需要你、阅读智能体、回答问题或直接进入会话，无需传输整个桌面画面。

CLI · 低带宽远程控制
ssh studio-mac · ~/store

$ randcomp status

在线商店项目 · 3 个角色工作中 · 1 项需要你

开发询问：是否复用现有结账设计？

$ randcomp agent send developer-2 "是，复用现有设计。"

已发送给开发。

这里控制的项目、团队、消息和结果，与桌面应用完全相同。
3

在你的 AI 会话中

通过 MCP，在你的 AI 会话中使用 RandComp。

继续用自然语言和 AI 会话交流。请它检查 RandComp、总结团队状态，或把你的决定传给某个角色。MCP 把这段对话连接到同一个本地任务。

MCP · 对话式控制
AI 会话 · 已连接 RandComp MCP
问 RandComp，商店项目现在有什么需要我处理？
质检正在等待结账版本。开发需要你确认是否复用现有设计。
告诉开发可以复用，然后让质检验证移动端结账。
开发答案已送达
质检验证已排队
项目仍在应用中可见
4

工作返回时

检查一个汇总后的成果。

RandComp 把每个任务的帮手、文件和最终结果带回项目。打开成果、检查证据，只有在你认可后才结束工作。

成果 · 看证据，不看会话噪音

智能体大军背后的隐藏成本

一个智能体能完成，就只用一个。

更多智能体并不一定更好，隐藏的陷阱却是 Token 成本：每个会话都要读取上下文，协调也会继续消耗。简单工作交给一个专注会话；只有当并行工作或独立验证物有所值时，才组建团队。

小而独立的工作

美化这个 HTML 页面。

一个全新的前端会话，可能比五个智能体重复读取同一个项目更快、更省。无需额外规划和无意义的交接。

前端→ 成果

有关联、风险更高的工作

加入订阅付费功能。

只有当独立上下文、并行专业分工和独立验证确实值得额外 Token 与协调成本时，才使用更多角色。

产品后端前端支付质检

工作长期保存，上下文不必永久膨胀

恢复角色，而不是恢复一段巨大的对话。

持久状态是普通 Markdown：角色指令、任务目标、决定、消息、交接和成果。会话完成工作后可以停止。之后的新会话，甚至另一个受支持的 CLI，都能从保存的工作恢复，而不必继承每一个旧 Token。
