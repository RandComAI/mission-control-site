并行 AI 会话的本地控制中心

协调多个 AI 会话，不再靠手工管理。

一个越来越长的 AI 会话会把研究、决策、开发和评审混在同一份上下文里。拆成多个小会话可以让每项工作更专注，但你又不得不亲自分配工作、复制上下文、追踪进度、寻找结果。

RandComp Studio 把这些工作组织成一个任务，让不同角色在独立的命令行 AI 会话中运行，连接它们的交接，并在一个本地看板中显示所有会话、依赖、消息和结果。你可以随时检查或接管任何会话。

同一个本地系统，两种操作方式。直接使用桌面看板，或从支持 MCP 的 AI 会话中操作。当前版本需要 Apple 芯片、macOS 11 或更高版本，以及一个已安装并登录的受支持命令行 AI 智能体。

同时看清每个任务、角色和实时会话。

在左侧选择任务；它的协调员、角色会话、依赖和文件显示在中间。打开右侧的任意智能体，即可阅读实时会话、发送修正，或进入它的终端。

这是已经批准、正在实现的设计方向：更丰富的任务树、更易读的智能体工作内容，同时只需一次点击就能查看原始会话。

示例：构建一个小型在线宠物商店。

这是同一个具体任务，通过两种入口中的任意一种启动。两条路径都会创建同一个本地任务、角色会话、消息、文件和结果记录。

“构建一个带商品目录、购物车、结账和测试的小型在线宠物商店。让产品经理定义最小可用版本，开发负责实现，QA 负责验证。”

桌面应用

从看板开始

  1. 选择项目文件夹，在说出你想完成的工作中输入目标。
  2. 允许产品经理、开发和 QA 参与；协调员在这些角色之间拆分任务。
  3. 每个角色都在独立、专注的本地 AI 会话中工作。各自的指令和任务上下文保持分离，消息和依赖则保持连接。
  4. 查看任务图，打开实时会话，纠正智能体，并在同一任务视图中检查文件和最终结果。

在你的 AI 会话中

无需离开当前工具即可开始

  1. 在支持 MCP 的 AI 客户端中，一次性注册本地 randcomp mcp 进程。
  2. 让当前 AI 会话使用 RandComp Studio 完成同一个宠物商店目标，并说明要参与的角色。
  3. AI 客户端在本地调用 RandComp Studio；同一个任务和独立角色会话会出现在底层看板中。
  4. 在当前 AI 会话中询问进度摘要；需要查看任务图、完整记录、终端和文件时，再打开桌面应用。
两种入口，结果相同一个持久任务 → 独立角色会话 → 可见交接 → 集中的文件与结果。

保留你的工具，只添加团队协作层。

RandComp Studio 运行你已经在用的命令行 AI 智能体，为独立会话提供持久角色、清晰任务边界、可见协作和可检查的结果。它是协作管理层，而不是另一个 AI 智能体或聊天应用。

它也不替代 ChatGPT skills、Claude skills、插件或其他角色生态。你可以导入已有定义，检查转换结果，并只在确认后加入本地角色库。

  • 继续使用你偏好的运行器每个角色都能使用你选择的命令行 AI 智能体、已有账户与审批设置。当前预览版内置 Claude Code 和 Codex 运行器；支持更多运行器是下一步兼容性工作。
  • 复用你已有的专业能力把 Agent Skill、Claude agent 或 skill、导出的 GPT 或普通 Markdown 定义转换成团队可复用的角色。

拆分上下文，同时让团队保持连接。

一个全能会话不得不反复读取不断增长的历史，即使下一项工作只需要其中很小一部分。让研究、开发和评审分别使用只包含本职上下文的角色会话。RandComp Studio 把任务说明、依赖、消息和交接连接起来，同时由你掌控。

每个会话都通过你选择的运行器，在指定文件夹中工作。RandComp Studio 不保存任何模型凭据。

角色只需定义一次，每个任务都能组建合适的团队。

角色库就是可复用的团队：每个角色擅长什么、遵循哪些指令、以前做过什么。你可以在本地创建角色，也可以转换已在 ChatGPT、Claude 或其他智能体工具中使用的定义。只有任务雇用角色后，它才会成为运行中的智能体。

每个任务都可以由你亲自选角色，也可以让协调员从你允许的范围中选择。新会话开始和产生费用之前，决定权始终在你手中。

团队如何工作

会话更专注，交接看得见，控制权在你。

  1. 用一个明确结果创建任务，并选择它可以使用哪些角色。
  2. RandComp Studio 为每个被雇用的角色建立独立本地会话，并分配清晰职责。
  3. 团队可在角色之间传递工作和消息；你能从看板或 AI 会话查看实时状态。
  4. 需要时进入任何终端，最后检查记录的结果和任务产出的所有文件。

每个智能体都有自己的终端。

它们不是藏在后台的工作进程。每个智能体都是真实会话， 你可以观察、阅读、纠正，或完全接管。 

randcomp agent list TASK_ID
randcomp agent logs AGENT_ID
randcomp agent send AGENT_ID "..."
randcomp agent attach AGENT_ID

从命令输出中复制 TASK_ID 和 AGENT_ID。 会话不会随着启动命令结束而消失，所以关闭窗口不会终止工作。

整个团队使用同一套命令界面。

randcomp 和 randcomp-studio 是同一个程序；randcomp 更短。每条命令先写对象，再写动作：名词本身用于列出对象，后面的词指定对象，再后面的词说明要做什么。

创建工作、读取结果、与智能体沟通、导入别人写的角色，或查看整个团队，都使用同一种命令结构。

randcomp task create "发布落地页"
randcomp task list
randcomp task results TASK_ID
randcomp agent list TASK_ID

randcomp agent logs AGENT_ID
randcomp role import ./some-claude-skill --add
randcomp status

你需要什么

macOS 11 或更高版本，Apple 芯片
下载的是 arm64 版本，可在 M1 及更新芯片上运行。 暂不支持 Intel Mac。
Windows 和 Linux
即将推出。在相应版本可用前，下载按钮保持禁用。
Python：已内置
应用自带 Python 3.13，因为 macOS 在 /usr/bin 中提供的 Python 3.9 版本过旧。你无需另行安装，也不会影响现有 Python。
tmux：已内置
每个角色都在 tmux 会话中运行，会话不会随着启动命令结束。 应用已经带有 tmux，无需使用 Homebrew 安装。
你已经在用的命令行 AI 智能体
RandComp Studio 使用你已经安装并登录的运行器，本身不包含 AI 智能体。当前预览版内置 Claude Code（claude）和 Codex CLI（codex）定义，下一步将支持更多命令行智能体。

它能访问什么

  • 一个公司文件夹：首次运行时由你在文件选择器中指定。角色、任务和各智能体产出的内容都以普通文件保存在这里。
  • 你为工作指定的文件夹：智能体通过命令行 AI 工具读写它们，并遵循该 CLI 自己的审批设置，与单独运行该工具时完全相同。
  • 一个本地网页服务器：看板只绑定到 127.0.0.1 和操作系统提供的空闲端口，关闭窗口后停止。
  • 应用无需产品账户、没有遥测、没有托管服务：下载的应用无需注册，也不包含分析信标。这个公开网站使用注重隐私的 Cloudflare Web Analytics 统计访问量。你的命令行 AI 智能体仍按自身设置和隐私政策与其供应商通信。

安装并开始使用

需要独立窗口中的看板时，打开桌面应用；希望在现有 AI 工具中操作同一组任务和团队时，连接本地 MCP 服务器。

桌面应用

只需三步，不用输入命令。

  1. 下载 RandCompStudio-0.1.0-e5fe0ab9.dmg。
  2. 打开文件。窗口中会显示应用和 Applications 文件夹快捷方式。
  3. 拖动 RandComp Studio 到 Applications，然后从那里打开。

首次运行时，普通文件选择器会询问一次公司文件夹的位置，之后不再询问。 要移除应用，只需拖到废纸篓；你的公司文件夹属于你，不会被删除。

randcomp 命令通过菜单安装。 窗口中的每项操作都有终端等价方式。选择 RandComp Studio → Install the randcomp command in PATH 后，应用会把 randcomp 和 randcomp-studio 写入 ~/.local/bin， 并在该文件夹尚未加入 PATH 时提醒你。只有你主动选择后才会写入。

通过 MCP 在 AI 会话中使用

AI 客户端必须支持本地 MCP 服务器，并且 randcomp 必须在 PATH 中。若从磁盘映像安装，请打开 RandComp Studio 并选择 RandComp Studio → Install the randcomp command in PATH。Claude Code 的注册命令是：

claude mcp add -s user randcomp-studio -- randcomp mcp

MCP 服务器就是通过标准输入和标准输出通信的本地 randcomp mcp 进程。它与应用操作同样的任务、角色、智能体、会话、消息和结果文件。它不是托管服务，也不需要 RandComp Studio API 密钥。

或者从命令行安装

这是同一个工具，但没有应用程序包。如果你希望运行前阅读每一行代码，可以选择这种方式。 它需要你自行准备 Python 3.11 或更高版本和 tmux；磁盘映像版本则已经内置这些依赖。 

tar -xzf randcomp-studio.tar.gz
cd randcomp-studio
./install.sh

install.sh 会把 randcomp 放进 ~/.local/bin； macOS 默认不会把这个目录加入 PATH。如果安装脚本提示，请把它输出的那一行加入 ~/.zshrc，打开新终端，再运行 randcomp。

randcomp-studio.tar.gz — 建议先在文本编辑器中打开 install.sh；它很短，并包含全部安装步骤。 它只创建 ~/.local/bin/randcomp 和 ~/.local/bin/randcomp-studio 两个脚本，指向你解压的文件夹和找到的 Python。它不会安装软件包、不会向其他位置复制文件，也不会启动后台服务。

RandComp Studio 在你的机器上运行，只访问你选择的文件夹，并使用你已经登录的命令行 AI 智能体。 阅读中文文档。
